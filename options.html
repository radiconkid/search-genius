Search Options

You can register up to 5 search options to show in the context menu.
The search engine can be chosen per option, and the prefix is a string prepended to the selected text when searching (e.g. site:stackoverflow.com).
The settings here are reflected identically in the context menu on desktop and in the popup panel shown on text selection in environments without contextMenus support (e.g. Firefox for Android / Iceraven).

Custom search engines

You can add your own search engines. Enter a name and a search URL containing %s where the query should be inserted (e.g. https://example.com/search?q=%s).

Search operator cheat sheet

Search operators are keywords that refine a query. Combine them in the prefix field to search like an expert.

Basic filters

Purpose Example Effect
Exact match "search engine optimization" Pages containing the exact phrase
Exclude jaguar -car Pages that do not contain the excluded word
OR search SEO OR SEM Pages containing either term
Wildcard "the most * way" Any word can fill the *
Range camera 2020..2024 Numeric or year range

Site and page structure

Example Effect
site:example.com Check the indexed pages of a domain
site:example.com "keyword" Search only within a specific site
intitle:"review" laptop Pages with the word in the title
allintitle:SEO tools comparison Pages with all words in the title
inurl:blog Pages with the string in the URL
intext:"pricing" Pages with the word in the body
related:example.com Related sites (currently less accurate)

File types

Example Effect
filetype:pdf market report 2025 PDF documents
filetype:xlsx sales template Excel files
site:go.jp filetype:pdf whitepaper Government PDF whitepapers

Especially useful when looking for reliable primary sources.

Tips

  • Start broad, then narrow down while checking the results.
  • Use exclusion (-) to remove noise such as unrelated fields with the same name.
  • Combine site: and filetype: to jump straight to primary sources.
  • Searching in English often changes the amount of information significantly.

Google may not strictly process operators these days. If results differ from your expectations, adjust by adding quotes or reducing words. Many operators also work on Bing, DuckDuckGo and others, but the details differ.
