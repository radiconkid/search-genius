Search Options

You can register up to 5 search options to show in the context menu.
The search engine can be chosen per option, and the prefix is a string prepended to the selected text when searching (e.g. site:stackoverflow.com).
The settings here are reflected identically in the context menu on desktop and in the popup panel shown on text selection in environments without contextMenus support (e.g. Firefox for Android / Iceraven).
